# SEA PUPPIES 🦭

An interactive, original pixel-art visual essay about sea lion behavior, inspired by early-2000s digital pets and the aesthetics of a forgotten handheld game. Built as a self-contained static project for The Pudding Cup.

## Run

Open `index.html` in a current browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Controls

- **A / left arrow**: previous episode
- **B / Space or Enter**: switch on / interact / continue
- **C / right arrow**: next episode (when unlocked)
- **EN / RU**: switch narration language
- **SOUND**: optional synthesized retro beeps (not real animal recordings)

Eight episodes: food, communication, rescue, play, thermoregulation, grooming, sleep, and tagging. Interactions unlock context-specific facts. Animal illustration and animations are generated programmatically in Canvas without using third-party sprites or copyrighted reference artwork. The handheld device is an original vector/CSS interpretation, not a reproduction of a specific Tamagotchi model.

## Fact-checking and transparency

- Marine mammal basics: [NOAA Fisheries – California sea lion](https://www.fisheries.noaa.gov/species/california-sea-lion)
- Sea lion biology and behavior: [SeaWorld — Sea Lions](https://seaworld.org/animals/all-about/california-sea-lion/)
- Human impacts and entanglement: [NOAA Fisheries — Marine Mammal Entanglement](https://www.fisheries.noaa.gov/national/marine-life-distress/marine-mammal-entanglement)
- Rehabilitation and conservation: [The Marine Mammal Center](https://www.marinemammalcenter.org/)

All writing is original paraphrase. Gameplay exaggerates movement for clarity. Puppy-check labels are playful analogies, not scientific claims of identical behaviors. This is **not** a veterinary or rescue guide; never attempt an entanglement rescue yourself.

## Publication

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Originality considerations

The blend of a simulated digital pet and a single-character linear science story is the key authored concept. Pixel art, Tamagotchi-like button control, and retro UI aesthetics are existing visual conventions, not exclusive inventions. Distinctive work (narration, code, sprites, behavior simulations) is original to this prototype. Do not copy photos or sprite assets from reference projects without permission.
